# Worthout

**Every rep is worth it.**

Worthout is a home workout tracking application designed to help users plan, perform, and track their exercise routines.

It combines manual workout logging with guided workout sessions, allowing users to monitor their performance and track their fitness progress over time.

Worthout aims to make home workout tracking simple, accessible, and reliable, giving users the ability to manage their workouts even without an internet connection.

## Features

### Workout Tracking
- Manually log workout sessions.
- Record sets, repetitions, weights, and exercise duration.
- Track completed workouts and workout history.
- Monitor personal workout progress.

### Guided Workouts
- Follow planned workout routines.
- Track sets and repetitions during exercise sessions.
- Built-in rest timer between sets.
- Pause, resume, and skip exercises.

### Exercise Library
- Browse a collection of exercises.
- Filter exercises by muscle group, equipment, and difficulty.
- Support for bodyweight exercises and various home workout equipment, including:
  - Dumbbells
  - Resistance bands
  - Kettlebells
  - Pull-up bars
  - Weight plates
  - Workout benches
  - Exercise mats

### Progress Monitoring
- View workout history.
- Track exercise performance over time.
- Review workout statistics and activity trends.

### Offline Support
- Access essential workout features without an internet connection.
- Store workout records locally.
- Synchronize data with the cloud when connectivity is restored.

## Project Goals

Worthout aims to make home workout tracking simple, accessible, and reliable.

Instead of relying on a constant internet connection, users can manage their workouts locally and synchronize their progress when online.

The long-term goal is to build a flexible fitness platform that supports different exercise types, workout routines, and multiple users.
